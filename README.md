## Projects

**SoFi Technologies equity valuation** (complete)
A residual income valuation of SoFi, cross-checked against a bank comparable set and a
fintech comparable set, plus a reverse-engineering of the return assumptions embedded
in the current share price. The finding: at 2.5x tangible book the market requires
roughly 29% terminal ROTCE, while the forecast reaches 13.3% by 2028. The spread across
valuation methods is driven mainly by beta, not by operating performance, which makes
the classification question worth more than the execution question.

Files: `sofi-memo.pdf`, `sofi-model.xlsx`

**CFPB consumer complaint analysis** (in progress, shipping September 2026)
Comparing Chime, Block, PayPal, and Coinbase against Wells Fargo across 30 months of
federal consumer complaint data. Python cleaning pipeline, SQL analysis, Power BI
dashboard. Cleaning script and queries are published; the dashboard is in build.

Files: `cfpb/`
